## О проекте

**«Шаг за шагом»** — анонимный чат-бот на основе ИИ (YandexGPT), который поддерживает людей в выздоровлении от **алкогольной и наркотической** зависимости по принципам программы «12 шагов» 24 часа в сутки и при кризисе направляет к живой помощи.

## Из 01 — Предметная область

- Зависимость — хроническое заболевание; срыв переживают 40–60% людей (Hazelden Betty Ford).
- В 2025 году алкоголизм впервые диагностирован у 56,9 чел. на 100 тыс. — максимум с 2016 года (+30% к 2024).
- Работаем только с алкоголем и наркотиками — профиль наркодиспансеров (уточнено у специалиста-медика).
- «12 шагов» — программа Анонимных Алкоголиков; группы встречаются по расписанию, между встречами человек один.
- Бот — **равный консультант**: поддерживает на основе опыта выздоровления, но не врач и не замена группе.
- Участники: пациент, родственник, наркодиспансер / клиника, группы 12 шагов, экстренные службы.
- Конкуренты: Wysa, I Am Sober, «Ясно», группы АА, телефоны доверия. Наша ниша — русскоязычный анонимный ИИ на 12 шагах, встроенный в сайт клиники, с кризисным сценарием.
- Ограничения: 152-ФЗ (анонимность, данные в РФ), без диагнозов и лекарств, авторские права на литературу АА.

## Из 02 — Проблема

> Человек в выздоровлении остаётся без поддержки между встречами группы и после выписки — особенно ночью и в момент тяги. Именно тогда чаще всего случаются срывы.

- Решение: анонимный ИИ-собеседник 24/7 + кризисный сценарий (112, телефон доверия, клиника).
- Не решаем: не лечим, не ставим диагнозы, не заменяем врача и группу.
- Метрики: доля ночных диалогов, возвраты через 7/30 дней, срабатывания кризисного сценария, оценки ответов.

## Из 03 — Функционал

**Роли:** пациент, родственник (без регистрации), администратор клиники, администратор системы.

**MVP к 1 декабря:**
- веб-чат с ИИ-консультантом;
- анонимный вход;
- ответы с опорой на базу историй и 12 шагов;
- определение кризиса и карточка помощи;
- виджет для сайта клиники + демо-страница клиники;
- счётчик трезвых дней, удаление истории;
- Docker и развёртывание в Яндекс Облаке.

**Если успеем:** кабинет клиники (DataLens), «шаг дня», режим для родственников, голосовой ввод.

### Как идёт сообщение

1. Пользователь пишет в чат → фронтенд отправляет на бэкенд.
2. Бэкенд проверяет на кризис (ключевые слова + классификация ИИ). Кризис → карточка помощи.
3. Нет кризиса → поиск в базе знаний (AI Search) → YandexGPT с системным промптом → ответ.

### Защита от обхода ограничений ИИ

Системный промпт с жёсткой ролью → фильтр входящих сообщений → проверка каждого ответа перед показом → кризисную карточку показывает код, а не ИИ → автотесты на известные атаки.

### Инфраструктура

- Docker (бэкенд + фронтенд), `docker-compose` для локального запуска.
- Яндекс Облако: Serverless Containers, Container Registry, Object Storage, Managed PostgreSQL, Lockbox.
- Код: GitHub (основной) + SourceCraft (зеркало). Задачи: Яндекс Трекер.
- Тесты: pytest (бэкенд), Playwright (сценарии в браузере).
